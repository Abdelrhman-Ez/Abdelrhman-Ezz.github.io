ABDELRHMAN EZZAT — PORTFOLIO WEBSITE
===================================

FILES
- index.html : page content and sections
- style.css  : responsive layout, colors, and visual styling
- script.js  : mobile menu, project filters, reveal effects, current year

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to preview in your browser.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and open your portfolio repository. If you want the site at
   https://abdelrhman-ez.github.io, the repository should be named:
   Abdelrhman-Ez.github.io
2. Upload/replace index.html, style.css, script.js, and README.txt in the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait a few minutes and open your GitHub Pages URL.
